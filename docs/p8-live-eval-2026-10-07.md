## Defect discovered during qualification

The initial live conversation case:

```text
Je veux un café. Combien il coûte ?
```

revealed a real quality issue.

The model originally returned an optional politeness suggestion for `Je veux un café` while failing to surface the genuine question word-order error.

P8 hardened `languages.conversation` so balanced/coach feedback must prioritize a clear genuine grammatical error before optional politeness, register, or naturalness suggestions.

A regression assertion was added to the evaluation suite.

## Defect requalification

After the prompt hardening, the affected live French café case returned a genuine error:

```text
category: word_order
original: Combien il coûte ?
correction: Combien coûte-t-il ?
```

The model also recognized the valid conversational alternative:

```text
Il coûte combien ?
```

The targeted conversation rerun passed the hardened error-priority requirement.

## Evaluation precision refinement

Two unfinished scenario cases showed that `not_yet` and `progressing` can both be semantically correct descriptions of partial objective completion.

The evaluator was refined to accept an explicit set of valid objective signals rather than force a false single-label distinction.

This was an evaluator-quality correction, not a model defect.
